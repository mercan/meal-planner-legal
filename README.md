# Meal Planner help and legal pages

Static bilingual GitHub Pages site. No build step, tracking scripts, or external fonts.

Public URL: https://mercan.github.io/meal-planner-legal/

English pages are in the root; Turkish equivalents are in `tr/`. Edit both languages when updating a policy. Support: meal-planner@meloryn.app.

Publish from the `main` branch, repository root. Preview with `python3 -m http.server 8098`.

Content reflects the current anonymous-account, RevenueCat, FatSecret, and deletion implementation. Revisit policies before adding providers, analytics, sharing, new retention practices, or new data collection. These pages do not independently verify legal compliance or mailbox delivery.
